# examples/

CLI-д командыг файлаас уншуулж туршихад зориулсан өгөгдөл. Файл бүрд `.txt` (командууд) ба
`.expected.txt` (хүлээгдэх гаралт) гэсэн хос бий. Нэгж нь бүгд **byte**, санах ойн хэмжээ **1000**.

Ажиллуулах (repository-ийн үндсэн фолдероос):

    python src/cli.py 1000 < examples/example1.txt          (Windows)
    python3 src/cli.py 1000 < examples/example1.txt         (Linux)

Гаралтыг `.expected.txt`-тэй харьцуулна. Автоматаар шалгах бол: `python -m unittest discover tests`
(`test_cli.py` дотор `test_examples_match_expected_output` гэсэн тест бий).

| Файл | Юуг үзүүлэх вэ | Гол хүлээгдэх үр дүн |
|---|---|---|
| `example1.txt` | Үндсэн жишээ: хүсэх, чөлөөлөх, best-fit, compaction | Эцсийн STAT: `[0:299] P2`, `[300:549] P4`, `[550:999] Unused` |
| `example2_fits.txt` | First/Best/Worst-fit гурав өөр hole сонгодог | Ижил 70 byte-ын хүсэлт: F -> `[0:69]`, B -> `[250:319]`, W -> `[380:449]` |
| `example3_compaction.txt` | Fragmentation: нийт чөлөөт 400 боловч 350 хүсэлт амжилтгүй, compaction-ий дараа амжилттай | `RQ E 350 F` эхэндээ алдаа, `C`-ийн дараа `E-д [600:949] олгов` |
| `example4_errors.txt` | Буруу оролт: хэмжээ 0, сөрөг, "abc", буруу стратеги, аргумент дутуу, давхар нэр, нэрэнд зай, байхгүй процесс, хэт том хүсэлт, үл мэдэгдэх команд, хоосон мөр | Бүх тохиолдолд программ унахгүй, "Алдаа" эсвэл "Хэрэглээ" мессеж гарна |

## Хэрхэн баталгаажуулсан

`example1`, `example2_fits`, `example3_compaction`-ий хүлээгдэх `STAT` гаралтыг **гараар бодож** (цаас, харандаагаар)
дараа нь программын гаралттай тулгасан. `.expected.txt` файлууд нь тулгасан гаралтын хуулбар бөгөөд код өөрчлөгдөхөд
зан үйл нь эвдрээгүйг шалгадаг (regression) тестэд ашиглагдана.

`example1.txt`-ийн гараар бодсон STAT:

    STAT 1:  [0:199] P1   [200:499] P2   [500:599] P3   [600:999] Unused
    STAT 2:  [0:199] Unused   [200:499] P2   [500:999] Unused          (P1, P3 чөлөөлсний дараа, P3-ын hole төгсгөлийн hole-той нэгдсэн)
    STAT 3:  [0:199] Unused   [200:499] P2   [500:749] P4   [750:999] Unused   (RQ P4 250 B: 200-ийн hole багтахгүй, 500-ийн hole-д орно)
    STAT 4:  [0:299] P2   [300:549] P4   [550:999] Unused               (compaction)

## Өөрийн жишээ нэмэх

Шинэ `examples/<нэр>.txt` үүсгэнэ (командууд, сүүлд нь `X`). Гаралтыг гараар бодож шалгасны дараа:

    python src/cli.py 1000 < examples/<нэр>.txt > examples/<нэр>.expected.txt

Дараа нь `tests/test_cli.py` дотор `names` жагсаалтад нэрийг нэмнэ.
